# 横卷游戏判定 — 规则与数值细则

配套：[横卷平台方案.md](./横卷平台方案.md)

本文把**可实现的尺寸、速度、高度、出生点**一次写死。单位约定：

| 符号 | 含义 |
|---|---|
| 1 tile | **32 px**（世界单位与像素 1:1） |
| 地面脚底线 | `ground_y = 2.0` tiles（实体站立时脚底的世界 Y） |
| Y 轴 | **向上为正** |
| 物理 | `physics_hz = 60`，`dt = 1/60 s` |

派生公式（竖直抛体，同高度起落）：

- 腾空时间 `t_air = 2 * v0 / gravity`
- 最大跳高 `h_peak = v0² / (2 * gravity)`

## 2. 玩家（玛丽式小人，中性造型）

### 2.1 碰撞盒（AABB）

锚点：**脚底中心** `(x, ground_y)` 在站立贴地时。

| 姿态 | 宽 × 高 | 盒范围（相对脚底中心） | 像素 |
|---|---|---|---|
| **站立 / 走 / 空中** | 0.75 × 1.75 tiles | X: `[-0.375, +0.375]`，Y: `[0, 1.75]` | 24×56 |
| **蹲下** | 0.75 × **1.00** tiles | X: 同上，Y: `[0, 1.00]` | 24×32 |
| 死亡 | 可不更新盒 | — | — |

说明：

- MVP **没有独立「蹲下走」技能**；进入 `CROUCH` 时切换为**蹲下碰撞盒**（头顶变矮，用于躲避子弹和拾取钥匙）。
- `JUMP` 离地后立刻恢复**站立盒**。
- 蹲下时脚底仍贴地，不扣 `ground_y`。

### 2.2 传感器（碰撞判定用，可略小于实体）

| 传感器 | 尺寸 | 位置 |
|---|---|---|
| 脚底（着地 / 踩头） | 宽 0.50 × 高 0.15 | 贴 AABB 底边居中 |
| 头部（顶箱） | 宽 0.50 × 高 0.15 | 贴 AABB 顶边居中 |

### 2.3 移动与跳跃

| 参数 | 值 | 备注 |
|---|---|---|
| `move_speed` | **6.0** tiles/s | 192 px/s |
| `air_control` | **4.5** tiles/s | 空中左右控制 |
| `gravity` | **40** tiles/s² | |
| `jump_v`（短跳） | **10** tiles/s | |
| `stomp_bounce_v` | **8** tiles/s | 踩头后上弹 |

起跳时水平速度由当拍 `move` 决定：`LEFT/RIGHT + JUMP` 分别带水平速度，`IDLE + JUMP` 的水平速度为 0，不受上次朝向影响。

### 2.4 由公式得到的「跳跃高度 / 腾空」

| 动作 | `v0` | 峰高 `h_peak` | 腾空 `t_air` | 满速水平空距（约） |
|---|---|---|---|---|
| 短跳 | 10 | **1.25 tiles**（≈40 px） | 0.50 s | ≈ 3.0 tiles（×6.0） |
| 踩头反弹 | 8 | 0.80 tiles | 0.40 s | — |

验收约束（与坑宽对齐）：

- 短跳峰高约 1.25 tiles → **够顶到箱底（+2.75）**；箱底在 +2.75，站立头顶 +1.75，起跳后还需约 **1.00 tiles** 上升，短跳峰值可顶中。
- 短跳水平约 3 tiles → **稳定过 1 格坑**；当前生成器不生成连续 2 格坑。

### 2.5 落坑死亡

脚底中心 `y < ground_y - 0.5` 且所在列无实地 → 死亡。

## 3. 怪物

| 项 | 值 |
|---|---|
| AABB | **1.00 × 1.00** tiles（32×32 px） |
| 贴地 | 脚底 = `ground_y` |
| 移速 `enemy_speed` | **4.0** tiles/s（128 px/s，&lt; 玩家） |
| AI | 水平左右巡逻（`dir ∈ {−1,+1}`）；出生随机朝向；前方无实地则掉头 |
| 不掉坑 | 下一步脚下方无实地则掉头（不追玩家） |
| 同屏 | ≤ 2 |
| 出生 | 与玩家 Δx ≥ **10** tiles，落地列必须有实地 |

踩头：玩家脚传感器从上落入怪顶面，且 `vy ≤ 0`。

## 4. 子弹

| 项 | 值 |
|---|---|
| AABB | **0.40 × 0.32** tiles（约 13×10 px，扁弹） |
| 飞行高度（盒底） | **`ground_y + 1.15`**（约打在站立角色躯干；蹲下高 1.0 时可躲过，作为有意设计） |
| 盒顶 | `ground_y + 1.30` |
| 速度 | **8.0** tiles/s 向左（256 px/s） |
| 出生 X | `camera_x + view_w + 1.0`（镜头右缘外 1 tile） |
| 出生时相对玩家 | Δx ≥ max(12, `8.0 * (2/decision_hz + 0.25)`) tiles |
| 销毁 | 右缘 &lt; `camera_x - 1` |
| 同屏 | ≤ 2 |

`decision_hz=8` 时：`8 * (2/8 + 0.25) = 8 * 0.5 = 4`，故下界取 **max(12,4)=12** tiles。

## 11. 修订说明

- 蹲下：对应独立蹲姿碰撞盒，非自由蹲走。
- 子弹高度刻意打在站立躯干；蹲姿可能躲弹。  
- 跳高由 `v0/g` 导出，调 `jump_v` / `gravity` 后须重算本节并跑黄金用例。  
- 贴图见 §10 与 `frontend/public/assets/platform/`。
